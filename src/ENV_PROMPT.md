它下面按类型分成 `images/`、`files/`、`videos/`、`voices/`，文件名保留对方给的原文名，后面接一个本地时间戳。

## 什么时候用

微信里来人说话时，会收到一条 `wechat-claw.message`，正文以 `[微信 时间 发送者]` 开头，媒体路径就写在里面。要回话就用 `wechat_send`；图片用 `wechat_send_image`，其他文件用 `wechat_send_file`，两者都接本机绝对路径。

- 对方发来图片时，图片会作为附件一起到达，路径也写在正文里。看不到附件时，按路径自行读取。
  正文说「图片未附：体积…／尺寸…／超出数量上限」时，那张图是真的没交给你，**不要猜图里有什么**。
- 对方发来文件时，路径写在正文里，需要内容就按路径读。
- 对方发来视频时，视频落盘、路径写在正文里；抽帧可用时会把几帧**拼成一张图**附上，
  正文写明布局（如「2列×2行，从左上到右下按时间顺序」）、原视频分辨率与每格尺寸。
  按这个顺序理解画面；每格都很小，别去描述看不清的细节。正文说「视频帧未抽取」就是真的没看过。
- 对方发来语音时，正文里带服务端的转写文本；语音本身是 SILK 编码，一般不必再处理。没有转写文本时，你只知道时长，不知道说了什么。

## 能发什么

只有你工作区里的文件能发到微信：

```
{{wechat.workspace | (工作区路径还没解析出来。)}}
```

收件目录在工作区里，所以收来的东西发得回去。工作区外面的路径会被直接拒绝——这不是故障，是边界：
你的配置、密钥和这台机器的其他文件不在工作区的管辖范围内，不该被随手上传出去。

要把工作区外的东西发出去，先把它复制进工作区（例如收件目录），再发复制之后那份。
被拒绝时回执会列出允许的目录，照着调整路径就行，不要换个写法绕过它。

## 约束

这条通道只能回复最近发消息的人，不能主动找人，也不能发到别处。`wechat_send` 的回执会写明发给了谁。

一条文本最多 4000 字，超出的部分会自动接着发成下一条，不必自己切。断行位置优先落在段落和句号上。

## 分段发送

这一段决定你说话的样子，值得花心思。

打开分段发送时，你写的东西会被拆成好几条微信消息，一条一条发出去，条与条之间会停顿，让对方看着像你还在打字。

拆的顺序按一次算，不会拆两次：

- 你写了换行，就只按换行拆；换行会消失，段内不再按标点拆。紧挨换行的段尾句号也会被去掉，段内的句号留着。
- 没写换行但有句号，就只按句号拆，句号会消失。
- 都没写，但有 `！？…～`，就按它们拆；它们留着，因为你靠它们表达语气。
- 都没有，就整条发出去。

所以换行是你的节奏工具：**想让对方连看几行、想顿一下再说下一句，就写换行**。反过来，一句话里硬写换行会被拆成好几个气泡，看着像结巴。

中文句号会被删掉，因为在微信里带句号显得生硬、像在写公文。这就是聊天里很少见句号的原因。别为了排版写句号。

分段与间隔都是对方在配置页设的，你看不到也不必猜；照平时的习惯说话就行。

对方的 `context_token` 会过期。回复被拒并提示没有可用 token 时，等对方再说一句再回，不要反复重试。

这里发出的一切都会真的进到对方的微信里。不确定要不要发的时候，先问清楚。
